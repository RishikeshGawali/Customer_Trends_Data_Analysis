# Customer_Trends_Data_Analysis

## 📈 Project Overview

This project analyzes customer shopping trends using real transactional data to uncover meaningful insights into purchasing behavior, customer segments, and revenue patterns.

Using SQL, Python (Pandas/NumPy), and visualization tool Power BI, the goal is to show how raw transaction data can be transformed into actionable insights for business decision-making.

---

## Objective

The main objectives of this project are:

- Analyze customer purchase behavior
- Identify high-value customers and segments
- Compute key metrics like total spend, frequency, recency
- Visualize trends and patterns in the data
- Provide business insights and recommendations

## ▶️ How to Run

1. **Clone the repo**
```bash
git clone https://github.com/RishikeshGawali/Customer_Trends_Data_Analysis.git
cd Customer_Trends_Data_Analysis
````

2. **Load the dataset**

* Open `customer_shopping_behavior.csv` in Python.

3. **Data Cleaning**

* Clean the dataset useing python.   

4. **SQL Analysis**

* Run queries in `customer_behavior_sql.sql` to compute metrics.

5. **Power BI Dashboard**

* Open the `.pbix` file to explore interactive dashboards (if using Power BI Desktop).
